### BSP层实现什么？：逆解算出的速度、方向，动作的FSM

#### 将大结构体中的数据（主要的控制与读取还是在大结构体中）
不要用小结构体进行分类封装，遍历与整理都很麻烦
系统的关键节点一定要在大结构体中

**Chassis大结构体示例（对着想）**

```c
struct Chassis_Data{
    Chassis_Mode_Enum chassis_mode;

    Velocity_Data input_world_velocity;
    Velocity_Data planning_velocity;

    /* 关于解算 */
    float wheel_cal_speed[4];
    float steer_cal_speed[4];
    float last_steer_cal_angle[4];
    float angle_err[4];
    float steer_back_angle[4];

    float wheel_radius;
    float chassis_radius;

    float target_yaw;
    float current_yaw;
    float err_yaw;

    float wheel_speed[4];
    float steer_angle[4];

    float increase_speed_temp;
    float reduce_speed_temp;

    uint8_t stop_flag;
    uint8_t park_flag;

    uint8_t radar_err_flag;
};
```
