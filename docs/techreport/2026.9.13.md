## 一个新的底盘该怎么纠手操的偏？

手柄映射加阈值，严格输出十字移动信号

imu:"纠偏"只有一种做法——航向闭环，位置不可闭环。

1. 航向锁定 

```
err_yaw = (target_yaw - current_yaw) * ANGLE_PI;  // 度 → 弧度
err_yaw = Limit_Max_Min(err_yaw);                 // 归一化到 ±π
Vw = pid_calc_by_error(&pid_w, err_yaw);
```

2. 世界系操控——摇杆值当场地系速度，再用 IMU 的 yaw 转到车体系（chassis.c:371-380）。这样不管车头朝哪，推前就是朝场地前方走。对"手操误差"的主观改善通常比 PID 本身还大，而且你有 IMU 就已经够了，不需要额外传感器。前提是轮系能横移。
