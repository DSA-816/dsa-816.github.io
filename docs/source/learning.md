## 语言基础与计算机概念

!!! info "明确概念"
    所有的资料分为manual与tutorial两种，大部分学生更倾向于tutorial，在tutorial中，叙述者会将你已经会的与不会的都讲一遍，其中还会不断重复某一“重点”，从而达到传统观念中“上了一节课”的概念传授目的，在内容上是有大量冗余的。manual则是浓缩的概念精华，在形式语义上不会有一句废话，概念结构也是环环相扣，这就导致对中间部分概念的缺失或模糊会直接导致看不懂后面的内容，从而直接放弃。看懂并运用manual对读者掌握系统知识的要求很高，但LLM的发展正逐步将认知体系的难度转变为信息数量的广度。
